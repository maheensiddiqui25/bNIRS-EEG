# EEG Processing and Analysis

## Overview

This folder contains the MATLAB scripts used to preprocess and analyse the EEG data collected as part of the NEST study.

The scripts document the original EEG processing and analysis pipeline, including EEG preprocessing, transformation into the original block structure, frequency-domain analysis, calculation of root mean square (RMS) power, statistical analysis and generation of EEG figures.

The raw EEG data are not included in this repository. Researchers will need access to the original data and associated study files to reproduce the analyses. The scripts retain the original subject identifiers, condition codes, data structures, channel selections and processing parameters used in the study.


## Requirements

- MATLAB.
- EEGLAB.
- Original EEG datasets.
- The relevant EEG channel-location file (`.locs`).
- Study-specific MATLAB functions. 
- Corresponding NIRS trial-rejection information required during EEG preprocessing.
- MATLAB workspace variables generated by preceding processing scripts.

Important variables used at different stages:

| Variable | Description |
|---|---|
| `ALLEEG` | EEG datasets used during preprocessing |
| `SubjectNum` | Original subject identifiers |
| `EEG_data_mat` | EEG data organised into the original block structure |
| `All_visual` | Condition-specific EEG datasets used in subsequent processing |
| `rmsInfant` | RMS values organised by channel, infant, condition and frequency band |
| `rms2_conditionXX_avg` | Block-averaged RMS values used for EEG topographical plots for condition XX|
| `A` | EEG channel-location information used by EEGLAB topographical plots |

Some scripts depend on variables generated in earlier scripts. Run the scripts in the order described below.

## Processing workflow

The EEG analysis consists of four main stages:

1. Basic EEG preprocessing.
2. Transformation of preprocessed EEG data into the original block structure.
3. Spectral analysis and calculation of RMS power.
4. Statistical analysis and figure generation.

### 1. Basic EEG preprocessing — `EEG_EasyFilePreprocessing`

The main steps include:

**Filtering**
- Bandpass filtering of EEG channels 1–32 using a second-order Butterworth filter, with cut-off frequencies of 0.1–100 Hz.
- Application of a 50 Hz notch filter using the EEGLAB `PMnotch` function.

**Channel locations**
- Addition of electrode location information using the study-specific channel-location file.
- Centring of channel locations using EEGLAB.

**Event marking**
- Identification and marking of events 
- Use of the corresponding NIRS trial information during event marking.

**Epoch segmentation**
- Segmentation of EEG data using the relevant experimental event codes.
- Epoch duration: -200 to 800 ms relative to event onset.
- Baseline correction using the -200 to 0 ms pre-stimulus interval.

**NIRS-related trial rejection**
- Retrieval of `rejepochsNIRS` information associated with EEG events.
- Removal of EEG epochs corresponding to trials rejected during NIRS processing, where rejection information is available.

**Bad-channel interpolation**
- Subject-specific bad-electrode lists are used for the relevant experimental conditions.
- Identified channels are interpolated using spherical interpolation in EEGLAB (`pop_interp`).

The subject-specific electrode lists and event codes are part of the original analysis and should be retained when reproducing the results.

### 2. Transform EEG data — `transform_all_EEG`

The transformation scripts organise the preprocessed EEG data into the original block structure.

The resulting `EEG_data_mat` structure retains the original block information and is used for subsequent spectral analysis. The spectral analysis is performed across the original recording blocks rather than treating the recording as a single continuous dataset.

### 3. Spectral analysis and RMS calculation — `spectral_visual`

The `spectral_visual` script calculates frequency-specific RMS power from the transformed EEG data.

**Preparation of the data**

The script:
- Defines the original subject identifiers using `SubjectNum`.
- Extracts condition-specific EEG data from `EEG_data_mat`.
- Pads recordings with fewer than 13 blocks with `NaN` values so that the block dimension is consistent.
- Organises the EEG data into a group-level array for subsequent analysis.

Padding with `NaN` allows recordings with fewer blocks to be retained without treating missing blocks as zero-valued EEG data.

**Frequency-domain transformation**

The spectral analysis uses:
- Sampling frequency: 500 Hz.
- Signal length: 500 samples.
- FFT length: the next power of two greater than or equal to the signal length.

The Fast Fourier Transform (FFT) is calculated for each channel, segment and block.

**Frequency bands**

RMS values are calculated for five frequency bands using the following FFT-bin index ranges in the original script:

| Frequency band | FFT indices |
|---|---|
| Theta | 4–7 |
| Alpha | 7–10 |
| Beta | 11–18 |
| Gamma | 22–63 |
| High gamma | 60–80 |

These are the index ranges used in the original MATLAB implementation. They should not be changed when reproducing the original analysis.

**Missing-value handling**

Missing RMS values are filled using a moving median with a window of four samples (`movmedian`, 4).

The script then calculates two versions of the RMS data:

- Baseline-corrected RMS: the mean of the first two blocks is subtracted from each block.
- Non-baseline-corrected RMS: the RMS values are retained without this subtraction.

**Block averaging**

The script calculates averages across blocks and then across infants, producing group-level RMS data for condition XX.

Main output variables include:

- `rms2_conditionXX_avg`: block-averaged, baseline-corrected RMS values.
- `rms2_conditionXX_avg_conditionXX`: block-averaged RMS values without baseline subtraction.
- `rms2_conditionXX_grand_avg`: group-level averages of baseline-corrected RMS values.
- `rms2_conditionXX_conditionXX_grand_avg`: group-level averages of non-baseline-corrected RMS values.

The condition-specific variable names should be retained according to the original analysis.

### 4. Statistical analysis — `rms_stats`

The `rms_stats` script performs statistical analysis of the RMS data.

The input variable, `rmsInfant`, is organised as:

`channel × infant × condition × frequency band`

**Collapse across conditions**

RMS values are averaged across the condition dimension using `nanmean`, producing channel × infant × frequency-band data.

**One-sample t-tests**

One-sample t-tests are performed across infants at each channel and frequency band to test whether RMS values differ from zero.

Missing infant values are excluded from the individual tests. Tests are performed where more than two valid observations are available.

**FDR correction**

Benjamini–Hochberg false discovery rate (FDR) correction is performed separately within each frequency band, across channels.

The script stores the t-statistics, uncorrected p-values, adjusted p-values and FDR significance mask.

**Occipital ROI analysis**

The occipital ROI consists of:
- O1: channel 7
- O2: channel 8
- Oz: channel 20

The median RMS value across these three electrodes is calculated for each infant and frequency band. One-sample t-tests are then performed across infants to test whether the occipital ROI RMS values differ from zero.

### 5. EEG figure generation

#### Figure 11 — EEG topographical plots

Script: `plot_rms_visual`

This script generates topographical plots of average EEG RMS power.

The script uses:
- `rms2_conditionXX_avg`, generated by `spectral_visual`.
- `conditionXX(1).chanlocs`, containing electrode location information.
- EEGLAB's `topoplot` function.

The group-level RMS data are averaged across infants and plotted separately for Theta, Alpha, Beta and Gamma, using a 2 × 2 layout.

#### Figure 12 — Posterior EEG variability across infants

The posterior EEG boxplot script visualises the distribution of EEG RMS values across infants at posterior electrodes.

The script uses:
- `r`, containing channel × infant × frequency-band EEG values.
- `A`, containing EEG channel-location information.

The posterior electrodes are selected using their labels:
- O1
- Oz
- O2
- PO3
- PO4
- Pz

The channel numbers are identified from `A.labels`.

For each frequency band, the script extracts RMS values for the selected posterior channels, generates boxplots showing the distribution across infants, overlays individual infant values using scatter points and adds a horizontal zero reference line.

No averaging across posterior channels is performed. Each electrode is displayed separately. The four frequency bands plotted are Theta, Alpha, Beta and Gamma.

## Reproducing the EEG analysis

The intended order of execution is:

1. `EEG_EasyFilePreprocessing`
2. `transform_all_EEG`
3. `spectral_visual`
4. `rms_stats`
5. `plot_rms_visual`
6. Posterior EEG boxplot script

The required variables must be available in the MATLAB workspace before running each dependent script.

## Important notes for reproducibility

- The raw EEG data are not distributed in this repository.
- Subject identifiers should match the original study.
- Original condition codes and subject-specific electrode lists should be retained.
- The original block structure should be preserved.
- The channel-location file and study-specific functions must be available.
- File paths should be updated to the researcher's local directory structure.
- The frequency-bin ranges and RMS calculation parameters should remain unchanged when reproducing the original analysis.

The scripts are provided to enable researchers with access to the relevant study data to apply the same processing and analysis procedures and reproduce the EEG results and figures.
