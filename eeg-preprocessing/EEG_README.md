# EEG MATLAB Analysis Pipeline

## Overview

This repository contains the MATLAB scripts used to preprocess and analyse EEG data collected as part of the NEST study. The pipeline processes EEG recordings, calculates root mean square (RMS) power across frequency bands, and generates group-level visualisations of EEG responses.

The EEG analysis is designed to complement the broadband near-infrared spectroscopy (bNIRS) analysis, allowing electrophysiological and haemodynamic responses to be examined together.

The scripts generate:
- EEG power estimates across four frequency bands: theta, alpha, beta and gamma.
- Scalp topographies showing average EEG power.
- Boxplots showing variability in posterior EEG power across infants.
- Combined bNIRS and EEG visualisations.

**Important:** The raw EEG data are not included in this repository. Researchers wishing to reproduce the analysis will need to request the original data from the authors thorugh a formal data sharing agreement.

## Analysis workflow

The EEG analysis follows the sequence below.

### 1. EEG preprocessing

**Script:** `EEG_EasyFilePreprocessing.m`

The original EEG recordings are preprocessed before being used in the subsequent analysis. The preprocessing includes:
- Band-pass filtering of the EEG channels.
- Notch filtering to remove line noise.
- Assignment of electrode locations.
- Event-related epoch extraction.
- Baseline correction.
- Identification and handling of bad electrodes, including interpolation where required.
- Rejection of EEG epochs based on the associated NIRS artefact information.

The output of this stage is the preprocessed EEG data used by the subsequent transformation script.

### 2. Transforming the EEG data

**Script:** `transform_all_EEG.m`

This script transforms the preprocessed EEG recordings into MATLAB data structures for the subsequent analysis.

The resulting `EEG_data_mat` structure retains the original recording block information. Keeping the block information allows the subsequent analysis to account for the structure of the original recordings.

### 3. Calculating RMS power

**Script:** `spectral_visual.m`

This script calculates RMS power across recording blocks for the EEG conditions and frequency bands.

The analysis considers four frequency bands:
- Theta
- Alpha
- Beta
- Gamma

The resulting RMS power variables are used in the subsequent statistical analysis and plotting scripts.

In particular, `rms2_conditionXX_avg` is used by `plot_rms_visual.m` to generate the EEG scalp topographies.

### 4. Statistical analysis

**Script:** `rms_stats.m`

This script performs statistical analysis of the EEG RMS power data generated during the preceding analysis.

### 5. Visualisation

The plotting scripts generate the EEG figures presented in the study.

## EEG figures

### Figure 11 – EEG scalp topographies

**Script:** `plot_rms_visual.m`

Generates scalp topographies showing average EEG power across the four frequency bands:
- Theta
- Alpha
- Beta
- Gamma

The script uses the RMS power data generated by `spectral_visual.m` and the electrode location information from the EEG recordings.

The data are averaged across infants to generate group-level scalp topographies.

### Figure 12 – Posterior EEG variability across infants

Generates boxplots showing the distribution of EEG RMS power across infants at six posterior electrodes:

- O1
- Oz
- O2
- PO3
- PO4
- Pz

Separate plots are generated for theta, alpha, beta and gamma power.

Individual infant data points are overlaid on the boxplots to show the variability across participants. The analysis retains the individual posterior electrode measurements rather than averaging across the selected electrodes.

### Figure 13 – Combined bNIRS and EEG visualisation

Generates individual infant visualisations combining bNIRS time courses and EEG scalp topographies.

The bNIRS plots show changes in:
- Oxygenated haemoglobin (HbO2)
- Deoxygenated haemoglobin (HHb)
- Oxidised cytochrome-c-oxidase (oxCCO)

The EEG plots show scalp topographies across theta, alpha, beta and gamma frequency bands.

The script contains different plotting configurations with different channel selections and axis limits. These configurations allow the bNIRS and EEG responses to be visualised using different plotting scales.

## Requirements

The analysis requires:

- MATLAB.
- The relevant MATLAB toolboxes required by the preprocessing, signal processing and statistical analysis scripts.
- EEGLAB, including the functions required for EEG scalp topography plotting.

The relevant toolboxes and external functions must be installed and available on the MATLAB path before running the scripts.
